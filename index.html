📘 기초 통계학

1. 기술통계학

데이터를 요약하고 설명하는 통계적 기법

중심경향성 (Central Tendency)

평균 (Mean): μ = Σx / n

중앙값 (Median): 중간 값

최빈값 (Mode): 가장 빈도 높은 값

🧮 평균·중앙값 계산기

산포도 (Dispersion)

분산 (Variance): σ² = Σ(x - μ)² / n

표준편차 (SD): σ = √σ²

변동계수 (CV): (σ / μ) × 100%

📊 정규분포 시각화

2. 확률의 기초

덧셈 법칙: P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

곱셈 법칙: P(A ∩ B) = P(A) × P(B|A)

베이즈 정리: P(A|B) = P(B|A) × P(A) / P(B)

🎲 베이즈 정리 계산기

3. 주요 확률분포

💡 퀴즈: 기초 통계

Q1: 데이터가 [10, 20, 30, 40, 100]일 때, 이상치에 가장 영향을 적게 받는 중심경향성 지표는?

📗 중급 통계학

1. 신뢰구간 (Confidence Interval)

모평균 (σ 알 때): x̄ ± Zα/2 × (σ / √n)

모평균 (σ 모를 때): x̄ ± tα/2 × (s / √n)

모비율: p̂ ± Zα/2 × √(p̂(1-p̂) / n)

📏 신뢰구간 계산기

2. 가설검정 (Hypothesis Testing)

1단계: 가설 설정

H₀ (귀무가설) vs H₁ (대립가설)

→

2단계: 유의수준

α = 0.05 (일반적)

→

3단계: 검정통계량

t = (x̄ - μ₀) / (s / √n)

→

4단계: 결론

p-value < α → H₀ 기각

🔬 t-검정 계산기
