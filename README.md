# 통계학 완벽 학습 가이드 📊

데이터로 가치를 창출하기 위한 통계학 완벽 학습 로드맵

## 목차

### 📘 [1단계: 기초 통계학](docs/01-basic-statistics.md)
- 기술통계학 (Descriptive Statistics)
- 확률의 기초
- 확률분포
- 표본추출과 표본분포

### 📗 [2단계: 중급 통계학](docs/02-intermediate-statistics.md)
- 추정 (Estimation)
- 가설검정 (Hypothesis Testing)
- 상관분석과 회귀분석
- 분산분석 (ANOVA)

### 📕 [3단계: 고급 통계학](docs/03-advanced-statistics.md)
- 다변량 통계분석
- 시계열 분석
- 베이지안 통계
- 기계학습을 위한 통계적 기법

## 시작하기

1. **문서 학습**: `docs/` 폴더의 마크다운 문서를 순서대로 학습
2. **인터랙티브 학습**: `index.html`을 브라우저에서 열어 인터랙티브하게 학습
3. **실습**: 각 섹션의 예제 코드를 직접 실행해보기

## 인터랙티브 웹페이지

```bash
# 웹 브라우저에서 index.html 파일을 열어주세요
```

인터랙티브 웹페이지 기능:
- 📊 실시간 데이터 시각화
- 🧮 인터랙티브 계산기
- 📈 그래프 시뮬레이션
- ✅ 학습 진행도 추적
- 💡 실습 예제

## 학습 방법 추천

1. **순차 학습**: 기초 → 중급 → 고급 순서로 진행
2. **반복 학습**: 이해가 안 되는 부분은 반복해서 학습
3. **실습 중심**: 이론을 배운 후 반드시 예제 실습
4. **프로젝트 적용**: 실제 데이터에 적용해보기

## 필요한 사전 지식

- 기초 수학 (대수학, 미적분학 기초)
- Python 또는 R 기본 문법 (선택사항)
- 데이터 분석에 대한 관심
