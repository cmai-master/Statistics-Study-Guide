## 📖 학습 내용

### 📘 [1단계: 기초 통계학](docs/01-basic-statistics.md)

**1. 기술통계학**
- 중심경향성 (평균, 중앙값, 최빈값)
- 산포도 (분산, 표준편차, 범위, IQR)
- 분포의 형태 (왜도, 첨도)
- 데이터 시각화

**2. 확률의 기초**
- 확률의 정의 (고전적, 상대도수적, 공리적)
- 확률의 법칙 (덧셈, 곱셈, 여사건)
- 조건부 확률
- 베이즈 정리 ⭐

**3. 확률분포**
- 이산분포: 베르누이, 이항, 포아송, 기하
- 연속분포: 균등, 정규, 지수, t, 카이제곱, F
- 정규분포의 특성
- 중심극한정리 ⭐

**4. 표본추출**
- 단순무작위, 층화, 계통, 군집 추출
- 표본분포
- 표준오차

---

### 📗 [2단계: 중급 통계학](docs/02-intermediate-statistics.md)

**1. 통계적 추정**
- 점추정 (불편성, 효율성, 일치성)
- 최대우도추정 (MLE)
- 구간추정 (신뢰구간) ⭐
- 표본 크기 결정

**2. 가설검정** ⭐
- 가설 설정 (귀무가설 vs 대립가설)
- 제1종/제2종 오류
- p-value 해석
- 일표본 검정 (z-검정, t-검정)
- 이표본 검정 (독립표본, 대응표본)
- 카이제곱 검정 (적합도, 독립성)
- 비모수 검정

**3. 상관분석과 회귀분석** ⭐
- 피어슨 상관계수
- 단순선형회귀
- 다중선형회귀
- 회귀 진단 (잔차분석, 영향력 분석)
- 다중공선성
- 변수 선택

**4. 분산분석 (ANOVA)**
- 일원 분산분석
- 사후 검정
- 이원 분산분석
- 반복측정 분산분석

---

### 📕 [3단계: 고급 통계학](docs/03-advanced-statistics.md)

**1. 다변량 통계분석**
- 주성분 분석 (PCA) ⭐
- 요인분석
- 판별분석
- 군집분석 (K-means, 계층적)
- 다차원척도법 (MDS)
- 구조방정식 모델링 (SEM)

**2. 시계열 분석** ⭐
- 시계열 분해 (추세, 계절성, 순환, 불규칙)
- 정상성과 차분
- 자기상관 (ACF, PACF)
- ARIMA 모델
- 계절 ARIMA
- 지수평활법
- VAR 모델

**3. 베이지안 통계** ⭐
- 베이지안 vs 빈도주의
- 사전분포, 우도, 사후분포
- 베이즈 인자
- MCMC (Gibbs Sampling, Metropolis-Hastings)
- 베이지안 회귀
- 계층적 베이지안 모형

**4. 기계학습을 위한 통계**
- 정규화 (Ridge, Lasso, Elastic Net) ⭐
- 교차검증
- 부트스트랩
- 앙상블 방법 (Bagging, Boosting, Stacking)
- 불균형 데이터
- 인과추론 ⭐
- 실험 설계 (A/B 테스트)
- 생존분석

## 🎮 인터랙티브 기능 사용법

### 📊 기술통계 계산기
```
1. 데이터 입력: 10, 20, 30, 40, 50
2. "계산하기" 클릭
3. 평균, 중앙값, 표준편차 등 자동 계산!
```

### 🎲 베이즈 정리 계산기
```
예제: 질병 검사
- P(질병) = 0.01
- P(양성|질병) = 0.99
- P(양성|정상) = 0.05
→ 양성일 때 실제 질병 확률 = ?
```

### 🔬 t-검정 계산기
```
A/B 테스트 데이터 입력
→ t-통계량, p-value 자동 계산
→ 통계적 유의성 자동 판단!
```

### 📈 회귀분석 계산기
```
X: 1, 2, 3, 4, 5
Y: 2, 4, 5, 4, 5
→ 회귀식: Y = 1.6 + 0.8X
→ 산점도 + 회귀선 그래프!
```

### 🧪 A/B 테스트
```
그룹 A: 1000명 중 100명 전환 (10%)
그룹 B: 1000명 중 130명 전환 (13%)
→ 통계적으로 유의한 차이! (p < 0.05)
```

### 🎯 중심극한정리 시뮬레이션
```
1. 모집단 분포 선택 (균등/지수/이봉)
2. 표본 크기: 30
3. 시뮬레이션 1000번 실행
→ 표본평균이 정규분포를 따름!
```

## 🎓 학습 완료 후 다음 단계

### Python으로 실습
```python
import numpy as np
import pandas as pd
from scipy import stats
import statsmodels.api as sm
import matplotlib.pyplot as plt
import seaborn as sns

# 예제: 회귀분석
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])
slope, intercept, r_value, p_value, std_err = stats.linregress(x, y)
print(f"회귀식: Y = {intercept:.2f} + {slope:.2f}X")
print(f"R² = {r_value**2:.4f}")
```

### R로 실습
```r
# 예제: t-검정
group_a <- c(23, 25, 27, 29, 31)
group_b <- c(33, 35, 37, 39, 41)
result <- t.test(group_a, group_b)
print(result)
```
