## 1. 기술통계학 (Descriptive Statistics)

### 1.1 데이터의 종류

#### 질적 데이터 (Qualitative Data)
- **명목척도 (Nominal)**: 순서가 없는 범주형 데이터
  - 예: 성별, 혈액형, 지역
  - 분석: 빈도, 최빈값

- **순서척도 (Ordinal)**: 순서가 있는 범주형 데이터
  - 예: 학년, 만족도 (매우불만족~매우만족), 등급
  - 분석: 빈도, 중앙값, 백분위수

#### 양적 데이터 (Quantitative Data)
- **이산형 (Discrete)**: 셀 수 있는 데이터
  - 예: 학생 수, 제품 판매량, 클릭 수
  - 특징: 정수 값, 중간 값 없음

- **연속형 (Continuous)**: 측정 가능한 데이터
  - 예: 키, 몸무게, 온도, 시간
  - 특징: 무한히 나눌 수 있음

### 1.2 중심경향성 (Measures of Central Tendency)

#### 평균 (Mean)
```
산술평균 = Σx / n

가중평균 = Σ(w × x) / Σw

기하평균 = (x₁ × x₂ × ... × xₙ)^(1/n)
```

**언제 사용?**
- 정규분포에 가까운 데이터
- 이상치가 적은 경우
- 수치 계산이 필요한 경우

**장점**: 모든 데이터 활용, 수학적 처리 용이
**단점**: 이상치에 민감

**실무 활용**:
- 평균 매출액 계산
- 평균 체류 시간 분석
- KPI 지표 산출

#### 중앙값 (Median)
```
데이터를 크기 순으로 정렬했을 때 중간 값

n이 홀수: (n+1)/2 번째 값
n이 짝수: n/2번째와 (n/2)+1번째 값의 평균
```

**언제 사용?**
- 이상치가 있는 데이터
- 소득, 부동산 가격 등
- 순서척도 데이터

**장점**: 이상치에 강건함
**단점**: 정보 손실

**실무 활용**:
- 중위 소득 계산
- 중간 가격대 파악
- 이상치가 많은 데이터 분석

#### 최빈값 (Mode)
```
가장 빈도가 높은 값
```

**언제 사용?**
- 명목척도 데이터
- 범주형 데이터
- 다봉분포 파악

**실무 활용**:
- 가장 인기 있는 제품
- 최다 선호 브랜드
- 주요 고객 연령대

### 1.3 산포도 (Measures of Dispersion)

#### 범위 (Range)
```
Range = 최댓값 - 최솟값
```

**특징**:
- 가장 단순한 산포도 측정
- 이상치에 매우 민감
- 데이터 분포에 대한 정보 부족

#### 사분위수 범위 (IQR - Interquartile Range)
```
IQR = Q3 - Q1

Q1: 25백분위수 (1사분위수)
Q2: 50백분위수 (중앙값)
Q3: 75백분위수 (3사분위수)

이상치 탐지:
하한: Q1 - 1.5 × IQR
상한: Q3 + 1.5 × IQR
```

**실무 활용**:
- 박스플롯 생성
- 이상치 탐지
- 데이터 분포 파악

#### 분산 (Variance)
```
모분산: σ² = Σ(x - μ)² / N

표본분산: s² = Σ(x - x̄)² / (n-1)
```

**왜 n-1로 나누나?**
- 불편 추정량(Unbiased Estimator)을 얻기 위함
- 표본에서 계산한 분산이 모분산을 과소추정하는 것을 방지
- 자유도(Degree of Freedom) 개념

**특징**:
- 제곱 단위라 해석이 어려움
- 수학적 처리에 유리

#### 표준편차 (Standard Deviation)
```
모표준편차: σ = √σ²

표본표준편차: s = √s²
```

**해석**:
- 원 데이터와 같은 단위
- 평균으로부터 평균적으로 얼마나 떨어져 있는가
- 작을수록 데이터가 평균 주변에 밀집

**실무 활용**:
- 위험도 측정 (금융)
- 품질 관리 (6σ)
- 성과 평가 변동성

#### 변동계수 (Coefficient of Variation)
```
CV = (s / x̄) × 100%
```

**언제 사용?**
- 단위가 다른 데이터셋 비교
- 평균이 다른 그룹 비교
- 상대적 변동성 측정

**예제**:
```
A제품: 평균 100만원, 표준편차 10만원 → CV = 10%
B제품: 평균 10만원, 표준편차 2만원 → CV = 20%
→ B제품이 상대적으로 더 변동이 큼
```

### 1.4 분포의 형태

#### 왜도 (Skewness)
```
Skewness = E[(X - μ)³] / σ³
```

**해석**:
- **0**: 대칭 분포
- **> 0**: 오른쪽 꼬리 (평균 > 중앙값)
  - 고소득자가 평균을 끌어올림
- **< 0**: 왼쪽 꼬리 (평균 < 중앙값)
  - 저소득자가 평균을 끌어내림

**실무 의미**:
- 소득 분포는 대부분 양의 왜도
- 왜도가 크면 평균이 대표성을 잃음
- 변환(로그, 제곱근)을 통해 정규화 가능

#### 첨도 (Kurtosis)
```
Kurtosis = E[(X - μ)⁴] / σ⁴
```

**해석**:
- **3**: 정규분포
- **> 3**: 뾰족한 분포 (Leptokurtic)
  - 중심에 데이터 집중
  - 두꺼운 꼬리 (극단값 多)
- **< 3**: 평평한 분포 (Platykurtic)
  - 데이터가 고르게 분산

**실무 의미**:
- 금융: 높은 첨도 = 극단적 수익률 가능성
- 리스크 관리에 중요
- 초과 첨도(Excess Kurtosis = Kurtosis - 3) 사용

### 1.5 데이터 시각화

#### 히스토그램 (Histogram)
- 연속형 데이터의 분포 확인
- 구간(bin) 선택이 중요
- 분포의 형태, 대칭성, 이상치 파악

#### 박스플롯 (Box Plot)
```
     |-----|     |-----|
     | Q1  | Q2  | Q3  |
     |-----|     |-----|
  min   IQR        max
```

**장점**:
- 여러 그룹 비교 용이
- 이상치 명확히 표시
- 중심, 산포, 왜도를 한눈에 파악

#### 산점도 (Scatter Plot)
- 두 변수 간 관계 파악
- 선형/비선형 관계
- 이상치 탐지

## 2. 확률의 기초

### 2.1 확률의 정의

#### 고전적 정의
```
P(A) = (사건 A가 일어나는 경우의 수) / (전체 경우의 수)
```

**조건**:
- 각 결과가 동등하게 가능해야 함
- 유한한 표본공간

**예제**: 주사위에서 짝수가 나올 확률
```
P(짝수) = 3/6 = 0.5
```

#### 상대도수적 정의
```
P(A) = lim(n→∞) (사건 A가 발생한 횟수) / (시행 횟수)
```

**특징**:
- 경험적 확률
- 대수의 법칙 기반
- 실제 데이터 기반 확률 추정

#### 공리적 정의 (Kolmogorov)
```
1. 0 ≤ P(A) ≤ 1
2. P(S) = 1 (전체 확률)
3. P(A ∪ B) = P(A) + P(B) (상호배타적 사건)
```

### 2.2 확률의 기본 법칙

#### 덧셈 법칙
```
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

상호배타적: P(A ∪ B) = P(A) + P(B)
```

**예제**: 카드에서 하트 또는 킹이 나올 확률
```
P(하트) = 13/52
P(킹) = 4/52
P(하트 ∩ 킹) = 1/52
P(하트 ∪ 킹) = 13/52 + 4/52 - 1/52 = 16/52
```

#### 곱셈 법칙
```
P(A ∩ B) = P(A) × P(B|A) = P(B) × P(A|B)

독립: P(A ∩ B) = P(A) × P(B)
```

**예제**: 두 번 연속 동전 던져 앞면이 나올 확률
```
P(앞면 ∩ 앞면) = 1/2 × 1/2 = 1/4
```

#### 여사건의 확률
```
P(A^c) = 1 - P(A)
```

**활용**: 적어도 하나가 일어날 확률
```
P(적어도 하나) = 1 - P(하나도 안 일어남)
```

### 2.3 조건부 확률

```
P(A|B) = P(A ∩ B) / P(B), P(B) > 0
```

**의미**: B가 일어났을 때 A가 일어날 확률

**예제**: 제품 불량률
```
P(불량) = 0.05
P(검사 통과|불량) = 0.1
P(검사 통과|정상) = 0.95

P(검사 통과 ∩ 불량) = 0.05 × 0.1 = 0.005
```

### 2.4 베이즈 정리 (Bayes' Theorem)

```
P(A|B) = P(B|A) × P(A) / P(B)

또는

P(A|B) = P(B|A) × P(A) / [P(B|A)×P(A) + P(B|A^c)×P(A^c)]
```

**용어**:
- P(A): 사전 확률 (Prior)
- P(A|B): 사후 확률 (Posterior)
- P(B|A): 우도 (Likelihood)
- P(B): 증거 (Evidence)

**예제**: 의학 검사
```
P(질병) = 0.01 (사전 확률)
P(양성|질병) = 0.99 (민감도)
P(양성|정상) = 0.05 (위양성률)

검사 결과 양성일 때 실제 질병일 확률?

P(질병|양성) = (0.99 × 0.01) / [(0.99 × 0.01) + (0.05 × 0.99)]
             = 0.0099 / 0.0594
             = 0.167 (16.7%)
```

**실무 활용**:
- 스팸 필터링
- 질병 진단
- 추천 시스템
- A/B 테스트 결과 해석

### 2.5 독립과 종속

#### 독립 (Independent)
```
P(A ∩ B) = P(A) × P(B)
P(A|B) = P(A)
P(B|A) = P(B)
```

**의미**: 한 사건이 다른 사건에 영향을 주지 않음

**예제**:
- 연속된 동전 던지기
- 복원 추출

#### 종속 (Dependent)
```
P(A ∩ B) ≠ P(A) × P(B)
```

**예제**:
- 비복원 추출
- 날씨와 우산 판매량

## 3. 확률분포

### 3.1 이산 확률분포

#### 베르누이 분포 (Bernoulli Distribution)
```
X ~ Bernoulli(p)

P(X = 1) = p (성공)
P(X = 0) = 1-p (실패)

E(X) = p
Var(X) = p(1-p)
```

**활용**:
- 클릭/비클릭
- 구매/비구매
- 승/패

#### 이항분포 (Binomial Distribution)
```
X ~ B(n, p)

P(X = k) = C(n,k) × p^k × (1-p)^(n-k)

E(X) = np
Var(X) = np(1-p)
```

**조건**:
- n번 독립 시행
- 각 시행은 성공/실패
- 성공 확률 p는 일정

**예제**: 10명 중 3명이 구매할 확률 (p=0.2)
```
P(X = 3) = C(10,3) × 0.2³ × 0.8⁷
         = 120 × 0.008 × 0.2097
         = 0.2013
```

**실무 활용**:
- 전환율 분석
- 품질 관리 (불량품 수)
- 설문 응답률

#### 포아송 분포 (Poisson Distribution)
```
X ~ Poisson(λ)

P(X = k) = (e^(-λ) × λ^k) / k!

E(X) = λ
Var(X) = λ
```

**언제 사용?**
- 단위 시간/공간당 사건 발생 횟수
- 희귀 사건
- n이 크고 p가 작을 때 (np = λ)

**예제**:
- 하루 평균 5건의 고객 문의 (λ=5)
- 정확히 3건이 올 확률?
```
P(X = 3) = (e^(-5) × 5³) / 3!
         = (0.0067 × 125) / 6
         = 0.1404
```

**실무 활용**:
- 웹사이트 방문자 수
- 콜센터 전화 수
- 교통사고 발생 건수
- 네트워크 패킷 도착

#### 기하분포 (Geometric Distribution)
```
X ~ Geometric(p)

P(X = k) = (1-p)^(k-1) × p

E(X) = 1/p
Var(X) = (1-p) / p²
```

**의미**: 첫 성공까지 시행 횟수

**예제**: 주사위에서 6이 나올 때까지 시행 횟수
```
p = 1/6
E(X) = 1/(1/6) = 6번
```

**실무 활용**:
- 첫 구매까지 접촉 횟수
- 고장까지의 시간

### 3.2 연속 확률분포

#### 균등분포 (Uniform Distribution)
```
X ~ U(a, b)

f(x) = 1/(b-a), a ≤ x ≤ b

E(X) = (a+b)/2
Var(X) = (b-a)²/12
```

**특징**:
- 모든 구간에서 동일한 확률
- 난수 생성 기본

**활용**:
- 임의 시간 선택
- 시뮬레이션

#### 정규분포 (Normal Distribution)
```
X ~ N(μ, σ²)

f(x) = (1/(σ√(2π))) × e^(-(x-μ)²/(2σ²))

E(X) = μ
Var(X) = σ²
```

**특징**:
- 대칭적 종 모양
- 평균=중앙값=최빈값
- 68-95-99.7 규칙

**68-95-99.7 규칙**:
```
P(μ-σ ≤ X ≤ μ+σ) ≈ 68.3%
P(μ-2σ ≤ X ≤ μ+2σ) ≈ 95.4%
P(μ-3σ ≤ X ≤ μ+3σ) ≈ 99.7%
```

**표준정규분포**:
```
Z ~ N(0, 1)

Z = (X - μ) / σ
```

**중심극한정리**: 표본 크기가 충분히 크면 표본평균은 정규분포를 따름

**실무 활용**:
- 키, 몸무게, 시험 점수
- 측정 오차
- 대부분의 통계적 추론

#### 지수분포 (Exponential Distribution)
```
X ~ Exp(λ)

f(x) = λe^(-λx), x ≥ 0

E(X) = 1/λ
Var(X) = 1/λ²
```

**특징**:
- 사건 간 대기 시간
- 무기억성 (Memoryless)
- 포아송 과정과 관련

**예제**: 평균 10분마다 고객 도착 (λ=1/10)
```
20분 이내 도착할 확률?
P(X ≤ 20) = 1 - e^(-20/10) = 0.865
```

**실무 활용**:
- 고객 도착 간격
- 기계 수명
- 서버 응답 시간

#### t-분포 (t-Distribution)
```
자유도: df = n-1

σ를 모를 때 사용
표본 크기가 작을 때
```

**특징**:
- 정규분포보다 두꺼운 꼬리
- df가 커질수록 정규분포에 근접
- df = 30 이상이면 정규분포와 유사

**활용**:
- 소표본 평균 검정
- 신뢰구간 추정

#### 카이제곱 분포 (Chi-square Distribution)
```
χ² ~ χ²(df)

자유도: df
```

**특징**:
- 양의 왜도
- 분산 추정에 사용
- 독립성 검정

**활용**:
- 적합도 검정
- 독립성 검정
- 분산의 신뢰구간

#### F-분포 (F-Distribution)
```
F ~ F(df1, df2)

두 자유도 필요
```

**활용**:
- 분산 비교
- ANOVA
- 회귀분석 유의성 검정

## 4. 표본추출과 표본분포

### 4.1 모집단과 표본

#### 모집단 (Population)
- 연구 대상 전체 집합
- 모수(Parameter): μ, σ, ρ (그리스 문자)
- 일반적으로 알 수 없음

#### 표본 (Sample)
- 모집단에서 추출한 일부
- 통계량(Statistic): x̄, s, r (로마 문자)
- 실제로 관측 가능

**목적**: 표본 통계량으로 모수 추정

### 4.2 표본추출 방법

#### 단순 무작위 추출 (Simple Random Sampling)
```
모든 개체가 동일한 확률로 선택
```

**장점**: 편향 없음, 통계적 이론 적용 가능
**단점**: 모집단 명부 필요, 비용

**방법**:
- 난수표 사용
- 컴퓨터 난수 생성
- 복원/비복원 추출

#### 층화 추출 (Stratified Sampling)
```
모집단을 동질적 층으로 나눈 후 각 층에서 추출
```

**장점**: 대표성 향상, 정밀도 증가
**단점**: 층 정보 필요

**예제**:
- 성별로 층화
- 지역별로 층화
- 소득 구간별 층화

**비례배분**: 각 층의 크기에 비례하여 추출

#### 계통 추출 (Systematic Sampling)
```
k = N/n (추출 간격)
첫 번째를 1~k 중에서 무작위 선택
이후 k 간격으로 추출
```

**장점**: 간편, 모집단에 골고루 분포
**단점**: 주기성 있으면 편향 가능

**예제**: 100명 중 10명 추출
```
k = 100/10 = 10
첫 번째: 3번 (무작위)
이후: 13, 23, 33, ..., 93번
```

#### 군집 추출 (Cluster Sampling)
```
군집을 단위로 추출
선택된 군집 내 전수 조사
```

**장점**: 비용 절감, 모집단 명부 불필요
**단점**: 군집 내 동질성이 높으면 효율 낮음

**예제**:
- 학교 단위로 추출 후 전교생 조사
- 지역 단위 조사

### 4.3 표본분포 (Sampling Distribution)

#### 표본평균의 분포
```
X̄ ~ N(μ, σ²/n) (모집단이 정규분포)

중심극한정리:
n이 충분히 크면 (n ≥ 30)
X̄ ~ N(μ, σ²/n) (모집단 분포 무관)
```

**표준오차 (Standard Error)**:
```
SE(X̄) = σ/√n
```

**의미**:
- 표본평균의 표준편차
- 추정의 정밀도
- n이 커질수록 감소

**중심극한정리 (Central Limit Theorem)**:
```
lim(n→∞) P((X̄ - μ)/(σ/√n) ≤ z) = Φ(z)
```

**실무 의미**:
- 표본 크기가 크면 정규분포 가정 가능
- 통계적 추론의 기반
- n ≥ 30이면 일반적으로 충분

#### 표본비율의 분포
```
p̂ = X/n (표본비율)

E(p̂) = p
Var(p̂) = p(1-p)/n

np ≥ 10, n(1-p) ≥ 10이면
p̂ ~ N(p, p(1-p)/n)
```

**예제**: 전환율 추정
```
n = 100, X = 15
p̂ = 15/100 = 0.15
SE(p̂) = √(0.15 × 0.85 / 100) = 0.0357
```

#### 표본분산의 분포
```
(n-1)S²/σ² ~ χ²(n-1)
```

**활용**:
- 분산의 신뢰구간
- 분산의 가설검정

### 4.4 추정량의 성질

#### 불편성 (Unbiasedness)
```
E(θ̂) = θ
```

**의미**: 추정량의 기댓값이 모수와 같음

**예제**:
- E(X̄) = μ (불편 추정량)
- E(S²) = σ² (불편 추정량)

#### 효율성 (Efficiency)
```
Var(θ̂₁) < Var(θ̂₂)
```

**의미**: 분산이 작을수록 효율적

#### 일치성 (Consistency)
```
lim(n→∞) P(|θ̂ₙ - θ| < ε) = 1
```

**의미**: 표본 크기가 커질수록 모수에 수렴

#### 충족성 (Sufficiency)
```
표본의 모든 정보를 포함
```

### 4.5 표본 크기 결정

#### 평균 추정
```
n = (Z_α/2 × σ / E)²

E: 허용 오차
α: 유의수준
```

**예제**: 95% 신뢰수준, 오차 ±2, σ=10
```
n = (1.96 × 10 / 2)²
  = (9.8)²
  = 96.04 ≈ 97명
```

#### 비율 추정
```
n = Z²_α/2 × p(1-p) / E²

p를 모를 때: p = 0.5 (최대값)
```

**예제**: 95% 신뢰수준, 오차 ±3%
```
n = (1.96)² × 0.5 × 0.5 / (0.03)²
  = 1067.1 ≈ 1068명
```

**실무 팁**:
- 여유 있게 10-20% 더 추출
- 무응답률 고려
- 예산과 시간 제약 고려
