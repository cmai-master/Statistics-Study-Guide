## 1. 통계적 추정 (Statistical Estimation)

### 1.1 점추정 (Point Estimation)

#### 개념
```
θ̂: 모수 θ의 점추정량
단일 값으로 모수를 추정
```

**주요 점추정량**:
```
μ 추정: X̄ = Σx / n
σ² 추정: S² = Σ(x - x̄)² / (n-1)
p 추정: p̂ = x / n
```

**좋은 추정량의 조건**:
1. **불편성**: E(θ̂) = θ
2. **효율성**: Var(θ̂)이 최소
3. **일치성**: n→∞일 때 θ̂→θ
4. **충족성**: 모든 정보 활용

#### 최대우도추정 (Maximum Likelihood Estimation, MLE)
```
L(θ|x) = 우도함수

θ̂_MLE = argmax L(θ|x)
```

**과정**:
1. 우도함수 설정
2. 로그우도 계산
3. 미분하여 0이 되는 점 찾기
4. 최댓값 확인

**예제**: 정규분포의 평균 추정
```
L(μ|x) = ∏ (1/σ√(2π)) exp(-(xᵢ-μ)²/(2σ²))

log L(μ|x) = Σ[-(xᵢ-μ)²/(2σ²)] + 상수

∂(log L)/∂μ = Σ(xᵢ-μ)/σ² = 0

μ̂_MLE = Σxᵢ/n = X̄
```

**실무 활용**:
- 기계학습 모델 파라미터 추정
- 금융 모델 피팅
- 생존분석

### 1.2 구간추정 (Interval Estimation)

#### 신뢰구간 (Confidence Interval)
```
P(θ_L ≤ θ ≤ θ_U) = 1-α

θ_L: 하한
θ_U: 상한
1-α: 신뢰수준 (보통 95%)
```

**해석 (중요!)**:
- ❌ "모수가 이 구간에 있을 확률이 95%"
- ✅ "100번 반복하면 95번은 모수를 포함하는 구간이 만들어짐"

#### 모평균의 신뢰구간

**Case 1: σ를 알고 있을 때 (정규분포)**
```
X̄ ± Z_α/2 × (σ/√n)

95% 신뢰구간: X̄ ± 1.96 × (σ/√n)
99% 신뢰구간: X̄ ± 2.58 × (σ/√n)
```

**Case 2: σ를 모를 때 (t-분포)**
```
X̄ ± t_α/2(n-1) × (s/√n)

자유도 = n-1
```

**예제**:
```
표본: n=25, X̄=50, s=10
95% 신뢰구간 (df=24, t=2.064)

50 ± 2.064 × (10/√25)
= 50 ± 2.064 × 2
= 50 ± 4.128
= [45.872, 54.128]
```

**표본 크기와 신뢰구간**:
- n이 클수록 구간이 좁아짐 (정밀도 증가)
- n이 4배 → 구간 폭 1/2

**신뢰수준과 신뢰구간**:
- 신뢰수준 높을수록 구간이 넓어짐
- 90% < 95% < 99%

#### 모비율의 신뢰구간
```
p̂ ± Z_α/2 × √(p̂(1-p̂)/n)

조건: np̂ ≥ 10, n(1-p̂) ≥ 10
```

**예제**: 전환율 추정
```
n=1000, 성공=150
p̂ = 150/1000 = 0.15

95% 신뢰구간:
0.15 ± 1.96 × √(0.15×0.85/1000)
= 0.15 ± 1.96 × 0.0113
= 0.15 ± 0.0221
= [0.1279, 0.1721] 또는 [12.79%, 17.21%]
```

**실무 활용**:
- A/B 테스트 전환율
- 여론조사 지지율
- 품질관리 불량률

#### 모분산의 신뢰구간
```
[(n-1)s² / χ²_α/2(n-1), (n-1)s² / χ²_1-α/2(n-1)]

카이제곱 분포 사용
```

**주의**: 비대칭 구간!

#### 두 모평균 차이의 신뢰구간

**독립표본, 등분산 가정**:
```
(X̄₁ - X̄₂) ± t_α/2 × s_p × √(1/n₁ + 1/n₂)

s_p² = [(n₁-1)s₁² + (n₂-1)s₂²] / (n₁+n₂-2)
df = n₁ + n₂ - 2
```

**독립표본, 등분산 가정 안 함 (Welch's t-test)**:
```
(X̄₁ - X̄₂) ± t_α/2 × √(s₁²/n₁ + s₂²/n₂)

df = (s₁²/n₁ + s₂²/n₂)² / [(s₁²/n₁)²/(n₁-1) + (s₂²/n₂)²/(n₂-1)]
```

**대응표본 (쌍체 비교)**:
```
d̄ ± t_α/2(n-1) × (s_d/√n)

d: 차이값
```

**예제**: 다이어트 효과
```
전: [70, 75, 80, 72, 68]
후: [68, 73, 78, 70, 66]
차이: [2, 2, 2, 2, 2]

d̄ = 2, s_d = 0
95% 신뢰구간: [2, 2]
```

## 2. 가설검정 (Hypothesis Testing)

### 2.1 가설검정의 기본 개념

#### 가설 설정
```
H₀: 귀무가설 (Null Hypothesis)
  - 현상태, 차이 없음
  - 검정을 통해 기각하려는 가설

H₁ (또는 Hₐ): 대립가설 (Alternative Hypothesis)
  - 연구가설
  - 증명하고자 하는 가설
```

**예제**:
```
새로운 광고가 매출을 증가시키는가?

H₀: μ_new ≤ μ_old (증가 없음)
H₁: μ_new > μ_old (증가함)
```

#### 검정 방향

**양측검정 (Two-tailed)**:
```
H₀: μ = μ₀
H₁: μ ≠ μ₀

기각역: 양쪽 끝
```

**우측검정 (Right-tailed)**:
```
H₀: μ ≤ μ₀
H₁: μ > μ₀

기각역: 오른쪽
```

**좌측검정 (Left-tailed)**:
```
H₀: μ ≥ μ₀
H₁: μ < μ₀

기각역: 왼쪽
```

#### 오류의 종류

**제1종 오류 (Type I Error, α)**:
```
H₀가 참인데 기각
"억울한 사람을 처벌"

P(제1종 오류) = α (유의수준)
보통 α = 0.05 (5%)
```

**제2종 오류 (Type II Error, β)**:
```
H₀가 거짓인데 채택
"범인을 놓침"

P(제2종 오류) = β
검정력 = 1 - β
```

**오류 매트릭스**:
```
              |  H₀ 참    |  H₀ 거짓
--------------+-----------+-----------
H₀ 채택       |  ✓ 올바름 |  β 제2종
H₀기각       |  α 제1종  |  ✓ 올바름
```

**실무에서**:
- α 감소 → β 증가 (트레이드오프)
- 표본 크기 증가 → α, β 모두 감소
- 중요한 결정: α 낮게 (0.01)
- 탐색적 연구: α 높게 (0.1)

#### 검정 절차

**1. 가설 설정**
```
H₀, H₁ 명확히 정의
```

**2. 유의수준 결정**
```
α = 0.05 (일반적)
```

**3. 검정통계량 계산**
```
데이터로부터 계산
```

**4. 기각역 또는 p-값 결정**
```
임계값과 비교 또는
p-값과 α 비교
```

**5. 결론**
```
H₀ 기각 또는 채택
실무적 해석
```

### 2.2 일표본 검정

#### 일표본 z-검정 (σ를 알 때)
```
z = (X̄ - μ₀) / (σ/√n)

H₀: μ = μ₀
```

**예제**: 평균 키 검정
```
μ₀ = 170, σ = 10, n = 100, X̄ = 172

z = (172 - 170) / (10/√100)
  = 2 / 1
  = 2.0

양측검정 α=0.05: 임계값 ±1.96
|z| = 2.0 > 1.96 → H₀ 기각
```

#### 일표본 t-검정 (σ를 모를 때)
```
t = (X̄ - μ₀) / (s/√n)

df = n - 1
```

**예제**: 평균 대기시간 검정
```
H₀: μ = 10분
H₁: μ ≠ 10분
α = 0.05

n = 25, X̄ = 12, s = 5
t = (12 - 10) / (5/√25) = 2.0

df = 24, 임계값 = ±2.064
|t| = 2.0 < 2.064 → H₀ 채택
```

**p-값 접근**:
```
p-값 = P(|T| ≥ |t_obs|)

p-값 < α → H₀ 기각
p-값 ≥ α → H₀ 채택
```

**p-값 해석**:
- p < 0.001: 매우 강한 증거
- p < 0.01: 강한 증거
- p < 0.05: 증거 있음
- p < 0.1: 약한 증거
- p ≥ 0.1: 증거 부족

#### 일표본 비율 검정
```
z = (p̂ - p₀) / √(p₀(1-p₀)/n)

조건: np₀ ≥ 10, n(1-p₀) ≥ 10
```

**예제**: 전환율 개선 검정
```
H₀: p = 0.1 (기존 전환율)
H₁: p > 0.1
α = 0.05

n = 1000, X = 130, p̂ = 0.13

z = (0.13 - 0.1) / √(0.1×0.9/1000)
  = 0.03 / 0.00949
  = 3.16

우측검정 임계값 = 1.645
z = 3.16 > 1.645 → H₀ 기각
전환율이 개선되었다!
```

### 2.3 이표본 검정

#### 독립표본 t-검정
```
t = (X̄₁ - X̄₂) / (s_p × √(1/n₁ + 1/n₂))

H₀: μ₁ = μ₂
```

**등분산 검정 (F-검정)**:
```
F = s₁² / s₂² (s₁² > s₂²)

H₀: σ₁² = σ₂²
```

**예제**: A/B 테스트
```
A그룹: n₁=50, X̄₁=100, s₁=15
B그룹: n₂=50, X̄₂=110, s₂=18

1. 등분산 검정
F = 18²/15² = 1.44
F_crit(49,49,0.05) ≈ 1.6
F < F_crit → 등분산 가정

2. t-검정
s_p² = [(49×15² + 49×18²) / 98] = 278.5
s_p = 16.69

t = (100-110) / (16.69×√(1/50+1/50))
  = -10 / 3.34
  = -2.99

df = 98, 임계값 ≈ ±2.0
|t| = 2.99 > 2.0 → H₀ 기각
B그룹 평균이 유의하게 높음
```

#### 대응표본 t-검정
```
t = d̄ / (s_d / √n)

d: 쌍차
H₀: μ_d = 0
```

**언제 사용?**:
- 사전/사후 비교
- 동일 대상 반복 측정
- 매칭된 쌍

**예제**: 교육 효과
```
사전: [60, 65, 70, 75, 80]
사후: [65, 70, 75, 82, 85]
차이: [5, 5, 5, 7, 5]

d̄ = 5.4, s_d = 0.894
t = 5.4 / (0.894/√5) = 13.5

df = 4, 임계값 ≈ 2.776
t = 13.5 > 2.776 → H₀ 기각
교육 효과 있음!
```

#### 두 비율의 검정
```
z = (p̂₁ - p̂₂) / √(p̄(1-p̄)(1/n₁ + 1/n₂))

p̄ = (x₁ + x₂) / (n₁ + n₂)
```

**예제**: 두 광고 클릭률 비교
```
광고A: n₁=1000, x₁=100, p̂₁=0.10
광고B: n₂=1000, x₂=130, p̂₂=0.13

p̄ = (100+130)/(1000+1000) = 0.115

z = (0.10-0.13) / √(0.115×0.885×(1/1000+1/1000))
  = -0.03 / 0.0143
  = -2.10

양측검정 임계값 = ±1.96
|z| = 2.10 > 1.96 → H₀ 기각
두 광고의 클릭률이 다르다
```

### 2.4 카이제곱 검정

#### 적합도 검정 (Goodness of Fit)
```
χ² = Σ (O - E)² / E

O: 관측빈도
E: 기대빈도
df = k - 1 (범주 수 - 1)
```

**예제**: 주사위 공정성
```
관측: [15, 18, 22, 16, 19, 10]
기대: [16.67, 16.67, 16.67, 16.67, 16.67, 16.67]

χ² = (15-16.67)²/16.67 + ... + (10-16.67)²/16.67
   = 6.72

df = 5, χ²_crit(0.05) = 11.07
χ² = 6.72 < 11.07 → H₀ 채택
주사위는 공정하다
```

**실무 활용**:
- 균등성 검정
- 정규성 검정
- 분포 적합성

#### 독립성 검정 (Test of Independence)
```
χ² = Σ (O - E)² / E

E = (행 합계 × 열 합계) / 전체 합계
df = (r-1)(c-1)
```

**예제**: 성별과 제품 선호도
```
        | A제품 | B제품 | 합계
--------+-------+-------+-----
남성    |  30   |  20   | 50
여성    |  10   |  40   | 50
--------+-------+-------+-----
합계    |  40   |  60   | 100

E(남성,A) = (50×40)/100 = 20
E(남성,B) = (50×60)/100 = 30
E(여성,A) = (50×40)/100 = 20
E(여성,B) = (50×60)/100 = 30

χ² = (30-20)²/20 + (20-30)²/30 + (10-20)²/20 + (40-30)²/30
   = 5 + 3.33 + 5 + 3.33
   = 16.66

df = (2-1)(2-1) = 1
χ²_crit(0.05) = 3.84
χ² = 16.66 > 3.84 → H₀ 기각
성별과 제품 선호도는 독립이 아니다
```

**실무 활용**:
- 범주형 변수 간 관계
- 마케팅 세분화
- 고객 특성 분석

#### 동질성 검정 (Test of Homogeneity)
```
여러 모집단의 분포가 같은지 검정
독립성 검정과 동일한 공식
```

### 2.5 비모수 검정 (Non-parametric Tests)

#### 언제 사용?
- 정규성 가정 위배
- 소표본 (n < 30)
- 순서척도 데이터
- 이상치가 많을 때

#### 윌콕슨 부호순위 검정 (Wilcoxon Signed-Rank Test)
```
대응표본 t-검정의 비모수 버전
차이의 부호와 순위 사용
```

**과정**:
1. 차이 계산
2. 절댓값 순위 매기기
3. 원래 부호 붙이기
4. 양의 순위 합, 음의 순위 합 계산
5. 작은 값을 검정통계량으로 사용

#### 맨-휘트니 U 검정 (Mann-Whitney U Test)
```
독립표본 t-검정의 비모수 버전
순위 기반
```

**활용**:
- 두 그룹 비교
- 중앙값 차이 검정
- 이상치가 있을 때

#### 크루스칼-왈리스 검정 (Kruskal-Wallis Test)
```
일원 ANOVA의 비모수 버전
세 그룹 이상 비교
```

## 3. 상관분석과 회귀분석

### 3.1 상관분석 (Correlation Analysis)

#### 피어슨 상관계수 (Pearson Correlation)
```
r = Σ[(x - x̄)(y - ȳ)] / √[Σ(x - x̄)² Σ(y - ȳ)²]

또는

r = Cov(X,Y) / (σ_x σ_y)
```

**특징**:
- **범위**: -1 ≤ r ≤ 1
- **r = 1**: 완벽한 양의 선형관계
- **r = -1**: 완벽한 음의 선형관계
- **r = 0**: 선형관계 없음

**해석**:
```
|r| = 0.0 ~ 0.2: 매우 약한 상관
|r| = 0.2 ~ 0.4: 약한 상관
|r| = 0.4 ~ 0.6: 보통 상관
|r| = 0.6 ~ 0.8: 강한 상관
|r| = 0.8 ~ 1.0: 매우 강한 상관
```

**가정**:
- 선형관계
- 정규분포
- 이상치 없음

**상관계수 검정**:
```
H₀: ρ = 0 (모상관계수가 0)

t = r√(n-2) / √(1-r²)
df = n - 2
```

**예제**:
```
광고비와 매출 상관
n = 20, r = 0.75

t = 0.75√18 / √(1-0.75²)
  = 0.75×4.24 / 0.661
  = 4.82

df = 18, 임계값 ≈ 2.101
t = 4.82 > 2.101 → 유의한 상관
```

**주의사항**:
- **상관 ≠ 인과**: 상관관계가 인과관계를 의미하지 않음
- **허구 상관**: 제3의 변수 영향
- **비선형**: 곡선 관계는 낮은 r
- **이상치**: 소수 점이 r을 크게 변화시킴

#### 스피어만 순위 상관계수 (Spearman's Rank Correlation)
```
r_s = 1 - (6Σd²) / (n(n²-1))

d: 순위 차이
```

**언제 사용?**:
- 순서척도 데이터
- 비선형 단조관계
- 이상치가 있을 때

#### 결정계수 (R²)
```
R² = r²

0 ≤ R² ≤ 1
```

**해석**: Y 변동의 R²%를 X로 설명 가능

### 3.2 단순선형회귀 (Simple Linear Regression)

#### 회귀모형
```
Y = β₀ + β₁X + ε

Y: 종속변수 (반응변수)
X: 독립변수 (설명변수)
β₀: 절편
β₁: 기울기
ε: 오차항 ~ N(0, σ²)
```

#### 최소제곱법 (Least Squares Method)
```
β̂₁ = Σ[(x - x̄)(y - ȳ)] / Σ(x - x̄)²
    = r × (s_y / s_x)

β̂₀ = ȳ - β̂₁x̄
```

**예제**: 광고비와 매출
```
광고비(X): [1, 2, 3, 4, 5]
매출(Y):   [2, 4, 5, 4, 5]

x̄ = 3, ȳ = 4
Σ(x-x̄)(y-ȳ) = 8
Σ(x-x̄)² = 10

β̂₁ = 8/10 = 0.8
β̂₀ = 4 - 0.8×3 = 1.6

회귀식: Ŷ = 1.6 + 0.8X
```

**해석**:
- β̂₁ = 0.8: 광고비 1 증가 → 매출 0.8 증가
- β̂₀ = 1.6: 광고비 0일 때 기본 매출

#### 회귀분석의 가정 (LINE)
```
L - Linear: 선형관계
I - Independent: 독립성
N - Normal: 정규성 (오차항)
E - Equal variance: 등분산성
```

**검증 방법**:
1. **선형성**: 산점도, 잔차도
2. **독립성**: Durbin-Watson 검정
3. **정규성**: Q-Q plot, Shapiro-Wilk 검정
4. **등분산성**: 잔차 vs 예측값 플롯, Breusch-Pagan 검정

#### 결정계수 (R²)
```
R² = SSR / SST = 1 - SSE / SST

SST = Σ(y - ȳ)²     (총 제곱합)
SSR = Σ(ŷ - ȳ)²     (회귀 제곱합)
SSE = Σ(y - ŷ)²     (오차 제곱합)
```

**해석**:
- R² = 0.7: 변동의 70%를 설명
- 높을수록 적합도 좋음
- 단, 변수 추가시 항상 증가 (과적합 주의)

#### 회귀계수 검정
```
H₀: β₁ = 0 (X가 Y에 영향 없음)

t = β̂₁ / SE(β̂₁)

SE(β̂₁) = √(MSE / Σ(x-x̄)²)
MSE = SSE / (n-2)
df = n - 2
```

#### 예측
```
점추정: Ŷ = β̂₀ + β̂₁X

예측구간 (새로운 Y):
Ŷ ± t_α/2 × SE(pred)

신뢰구간 (평균 E(Y)):
Ŷ ± t_α/2 × SE(fit)
```

**주의**: 외삽(Extrapolation) 위험

### 3.3 다중선형회귀 (Multiple Linear Regression)

#### 모형
```
Y = β₀ + β₁X₁ + β₂X₂ + ... + β_pX_p + ε
```

#### 추정
```
행렬 형태:
Y = Xβ + ε

β̂ = (X'X)⁻¹X'Y
```

#### 수정된 결정계수 (Adjusted R²)
```
R²_adj = 1 - (1-R²) × (n-1)/(n-p-1)

p: 독립변수 개수
```

**왜 사용?**:
- 변수 추가시 R²는 항상 증가
- R²_adj는 불필요한 변수 추가시 감소
- 모형 비교에 적합

#### 다중공선성 (Multicollinearity)
```
독립변수 간 높은 상관

문제점:
- 회귀계수 불안정
- 표준오차 증가
- 해석 어려움
```

**진단**:
```
VIF (Variance Inflation Factor)
VIF_j = 1 / (1 - R²_j)

R²_j: X_j를 다른 X들로 회귀

VIF > 10: 심각한 다중공선성
VIF > 5: 주의
```

**해결책**:
- 상관 높은 변수 제거
- 주성분 분석 (PCA)
- 릿지 회귀 (Ridge Regression)

#### 변수 선택
```
1. 전진 선택 (Forward Selection)
   - 하나씩 추가

2. 후진 제거 (Backward Elimination)
   - 하나씩 제거

3. 단계적 선택 (Stepwise)
   - 추가와 제거 반복
```

**기준**:
- AIC (Akaike Information Criterion): 낮을수록 좋음
- BIC (Bayesian Information Criterion): 낮을수록 좋음
- R²_adj: 높을수록 좋음

#### 더미 변수 (Dummy Variable)
```
범주형 변수를 회귀에 포함

k개 범주 → k-1개 더미

예: 성별
남성 = 0
여성 = 1

Y = β₀ + β₁(성별) + ε
```

**해석**:
- β₀: 남성의 평균
- β₀ + β₁: 여성의 평균
- β₁: 남녀 평균 차이

#### 교호작용 (Interaction)
```
Y = β₀ + β₁X₁ + β₂X₂ + β₃X₁X₂ + ε

β₃: 교호작용 효과
```

**의미**: X₁의 효과가 X₂ 수준에 따라 다름

### 3.4 회귀 진단

#### 잔차 분석
```
잔차(Residual): e = y - ŷ

표준화 잔차: e_i / √MSE
스튜던트화 잔차: 더 정교한 표준화
```

**잔차도 (Residual Plot)**:
- **잔차 vs 예측값**: 패턴 없어야 함
- **Q-Q plot**: 정규성 확인
- **잔차 vs 순서**: 독립성 확인

**패턴 해석**:
- 깔때기 모양: 등분산성 위배
- 곡선 패턴: 비선형 관계
- 주기성: 자기상관

#### 영향력 있는 관측치

**지렛대값 (Leverage)**:
```
h_ii = X_i(X'X)⁻¹X_i'

h_ii > 2(p+1)/n: 주의
```

**Cook's Distance**:
```
D_i = (e_i²/MSE) × (h_ii/(1-h_ii)) / (p+1)

D_i > 1: 영향력 큼
```

**DFFITS**:
```
영향력 측정 지표
```

**처리**:
- 확인: 데이터 오류?
- 분석: 왜 이상치?
- 제거 또는 별도 분석

## 4. 분산분석 (ANOVA)

### 4.1 일원 분산분석 (One-way ANOVA)

#### 목적
```
3개 이상 그룹의 평균 비교

H₀: μ₁ = μ₂ = ... = μ_k
H₁: 적어도 하나는 다름
```

**왜 t-검정을 반복하지 않나?**:
- 제1종 오류 누적
- k=3, α=0.05면 실제 오류율 ≈ 14.3%

#### ANOVA 표
```
변동원   | 제곱합 | 자유도 | 평균제곱 | F
---------+--------+--------+----------+---
그룹간   | SSB    | k-1    | MSB      | F
그룹내   | SSW    | n-k    | MSW      |
---------+--------+--------+----------+---
전체     | SST    | n-1    |          |
```

**공식**:
```
SST = Σ(y_ij - ȳ)²           (총 변동)
SSB = Σn_i(ȳ_i - ȳ)²         (그룹간 변동)
SSW = ΣΣ(y_ij - ȳ_i)²        (그룹내 변동)

SST = SSB + SSW

MSB = SSB / (k-1)
MSW = SSW / (n-k)

F = MSB / MSW ~ F(k-1, n-k)
```

**예제**: 3개 광고의 효과
```
A: [10, 12, 11, 13, 14]     ȳ₁ = 12
B: [15, 17, 16, 18, 14]     ȳ₂ = 16
C: [20, 22, 21, 19, 23]     ȳ₃ = 21
                            ȳ = 16.33

SSB = 5(12-16.33)² + 5(16-16.33)² + 5(21-16.33)²
    = 93.95 + 0.55 + 108.95
    = 203.45

SSW = Σ(각 그룹 내 편차제곱합)
    = 10 + 10 + 10
    = 30

MSB = 203.45 / 2 = 101.73
MSW = 30 / 12 = 2.5

F = 101.73 / 2.5 = 40.69

F_crit(2, 12, 0.05) ≈ 3.89
F = 40.69 > 3.89 → H₀ 기각
광고 효과가 다르다!
```

#### 가정
```
1. 정규성: 각 그룹이 정규분포
2. 등분산성: 모든 그룹의 분산 동일
3. 독립성: 관측치가 독립
```

**검증**:
- Levene 검정 (등분산성)
- Shapiro-Wilk 검정 (정규성)

**가정 위배시**:
- Welch ANOVA (등분산 가정 불필요)
- Kruskal-Wallis 검정 (비모수)
- 변환 (로그, 제곱근)

### 4.2 사후 검정 (Post-hoc Tests)

#### 왜 필요?
```
ANOVA는 "차이 있음"만 알려줌
어느 그룹이 다른지는 모름
```

#### Tukey HSD (Honestly Significant Difference)
```
HSD = q_α × √(MSW / n)

q: 스튜던트화 범위 분포

|ȳ_i - ȳ_j| > HSD → 유의한 차이
```

**특징**:
- 가장 보수적
- 모든 쌍 비교
- 등분산 가정

#### Bonferroni 보정
```
α_adj = α / m

m: 비교 횟수

각 비교를 α_adj로 검정
```

**특징**:
- 매우 보수적
- 간단함
- 검정력 낮음

#### Scheffe 검정
```
가장 보수적
모든 대비(contrast) 가능
```

#### Dunnett 검정
```
대조군과 비교할 때
```

### 4.3 이원 분산분석 (Two-way ANOVA)

#### 모형
```
Y_ijk = μ + α_i + β_j + (αβ)_ij + ε_ijk

α_i: 요인 A 효과
β_j: 요인 B 효과
(αβ)_ij: 교호작용 효과
```

#### ANOVA 표
```
변동원      | 제곱합 | 자유도       | F
------------+--------+--------------+---
A           | SSA    | a-1          | MSA/MSE
B           | SSB    | b-1          | MSB/MSE
A×B         | SSAB   | (a-1)(b-1)   | MSAB/MSE
오차        | SSE    | ab(n-1)      |
------------+--------+--------------+---
전체        | SST    | abn-1        |
```

**예제**: 광고 유형과 시간대
```
요인 A: 광고 유형 (이미지, 동영상)
요인 B: 시간대 (아침, 저녁)

가설:
H₀_A: 광고 유형 효과 없음
H₀_B: 시간대 효과 없음
H₀_AB: 교호작용 없음
```

#### 교호작용 (Interaction)
```
한 요인의 효과가 다른 요인 수준에 따라 다름
```

**해석**:
- 교호작용 유의 → 주효과 해석 주의
- 교호작용 그래프: 선이 교차하면 교호작용

### 4.4 반복측정 분산분석 (Repeated Measures ANOVA)

#### 언제 사용?
```
동일 대상 반복 측정
- 시간에 따른 변화
- 여러 조건 모두 경험
```

**장점**:
- 개인차 제거
- 검정력 증가
- 표본 크기 감소

**가정**:
- 구형성 (Sphericity)
- Mauchly 검정으로 확인
- 위배시 Greenhouse-Geisser 보정

### 4.5 공분산분석 (ANCOVA)

#### 목적
```
공변량(Covariate) 효과 제거 후 그룹 비교
```

**모형**:
```
Y = μ + α_i + βX + ε

X: 공변량
```

**예제**: 교육 방법 비교
```
종속변수: 사후 점수
공변량: 사전 점수
요인: 교육 방법

사전 점수를 통제한 후 교육 방법 효과 비교
```

**가정**:
- 회귀 기울기 동일 (homogeneity of regression slopes)
